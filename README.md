## Project Overview
This project showcases a multidisciplinary BIM model of a residential bungalow, integrating Architectural, Structural, and MEP disciplines into a coordinated 3D building model.

The architectural design was provided by the architect. I worked on developing the Structural and MEP models and performing structural analysis using ETABS.

## Project Scope

### 1. Architectural BIM
- Residential bungalow architectural layout.
- Interior space visualization and furniture arrangement.
- Doors, windows, flooring, and ceiling details.
- 3D architectural visualization.

### 2. Structural BIM
- Structural modeling of building components.
- Columns, beams, slabs, and structural elements.
- Structural model development based on architectural drawings.
- Structural coordination with the building layout.

### 3. MEP BIM
- Mechanical, Electrical, and Plumbing (MEP) modeling.
- MEP service integration within the building.
- Coordination of MEP systems with architectural and structural elements.

### 4. Structural Analysis
- Structural analysis performed using ETABS.
- Structural model preparation and analysis.
- Review of structural behavior and analysis results.

## Software & Tools

- ETABS – Structural Analysis
- Enscape – 3D Visualization

### How to use the viewer

1. Click the link above. It opens in your web browser, and no software install is needed.
2. If you are asked to sign in, use a free Autodesk account.
3. Wait a few seconds for the model to load.

| Action | How |
|--------|-----|
| Rotate (orbit) | Left-click and drag |
| Pan | Hold the middle mouse button, or Shift + left-click, and drag |
| Zoom | Scroll the mouse wheel |
| Reset the view | Click the **Home** icon |
| Hide or isolate parts | Open the **Model Browser**, then right-click an item |
| Check dimensions | Use the **Measure** tool in the toolbar |
| Cut through the model | Use the **Section** tool |
| Separate the parts | Use the **Explode** tool |

On a phone or tablet, use one finger to rotate and two fingers to pan and zoom.

## Clash Detection (Navisworks)

The 3D bungalow model (`banglow.nwc`) was checked for clashes in **Autodesk Navisworks Manage 2020** using the Clash Detective tool.

### Tests performed

| Beam vs Wall | Beams against walls | Done | 0 |
| MEP vs RCC | MEP services against reinforced concrete elements | Done | 0 |
